# FlowCHAOS

Comprehensive Hydraulic Analysis & Optimization System: water distribution network design and analysis
for Windows 10 or later. Freeware, licensed without a fee for commercial and non-commercial use under the
FlowCHAOS Freeware Licence (LICENSE).

## Download

The latest version is on the [Releases](../../releases/latest) page:

- `FlowCHAOS-Setup-<version>.exe`: the setup program (recommended)
- `FlowCHAOS-<version>-x64.msi`: the Windows Installer package, for IT departments and silent installs
  (`msiexec /i FlowCHAOS-<version>-x64.msi /qn`)

Each release lists the SHA-256 checksum of its files.

This repository holds the releases only; FlowCHAOS is developed in a private repository.
